# Changelog

All notable changes to this project are documented here.

## 2.0.0 — 2026-10-10

### Added

- Dynamic Find → Replace rows with a 12-pair limit
- Preview mode with occurrence and changed-frame counts
- Text-frame discovery inside selected groups
- Whole-word / phrase-boundary toggle
- Case-insensitive matching toggle
- Duplicate Find-value validation
- Blank replacement support for deleting matching text
- Clear and remove-row controls
- Confirmation before applying changes
- Portfolio documentation and repository presentation assets

### Improved

- Error messages and empty-state handling
- Regex escaping and replacement safety
- Result reporting
- Project structure and maintainability

## 1.0.0

- Initial five-row multi-frame text replacement prototype
- Direct selected TextFrame support
- Case-insensitive option
